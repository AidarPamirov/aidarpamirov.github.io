SmartFlow AI

Traffic Intersection Simulator

Браузерная модель городского перекрёстка. Машины едут по модели следования IDM и поворачивают по настоящим траекториям, светофор управляет каждым манёвром отдельно. Эксперименты сравнивают фиксированный и адаптивный алгоритмы на одном и том же потоке.

  • Повороты, развороты и конфликтные зоны без столкновений и взаимных блокировок
  • Левый поворот с уступкой встречным или в отдельной фазе
  • Статистика по каждому манёвру и воспроизводимые эксперименты по seed
  • 54 автотеста, GitHub Actions проверяет каждую публикацию
  • TypeScript
  • React
  • Vite
  • Canvas
  • IDM
  • GitHub Actions
